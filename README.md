# Pipeline de Dados com Databricks

## Objetivo

Pipeline ETL utilizando Databricks, PySpark e Delta Lake.

## Arquitetura

CSV → Bronze → Silver → Gold

## Tecnologias

- Databricks
- PySpark
- Delta Lake
- SQL
- Data Lakehouse

## Camadas

### Bronze
Dados brutos.

### Silver
Dados tratados e enriquecidos.

### Gold
Métricas analíticas para consumo.

## Resultado

Faturamento por categoria.
